## How the site works
- Static site generated by Python: `python3 _build/build.py` writes every page, `sitemap.xml`, `_headers`, `llms.txt`.
- Sources: `config.py` (facts, prices, photos, brand lists), `content.py` (home, services, prices, about), `areas.py` (towns), `brands.py` (digital/smart lock brands), `cars.py` (car brands), `guides*.py` (articles), `zh.py` (Chinese pages, still need a native-speaker check), `pages_extra.py` (contact, privacy), `icons.py` (SVG icons, no emoji), `styles.css`.
- Photos: originals in `assets/photos/` (not deployed); the build makes WebP/JPG sizes in `assets/img/photos/`.
- Page dates: `_build/lastmod.json` tracks when each page's `<main>` content last changed. The build uses that one date for the sitemap `lastmod`, the WebPage `dateModified` schema and the small "Last updated" line on each page (guides keep their own byline). Never fake dates.
- Brand (changed 10 Nov 2026): new red badge logo (cartoon Uncle Thomas in black cap, keys, house, car). Colours: white, near-black #151515 and one red #E71328 (hover/text red #C40F22, text red on white #B30D1F, light red on black #FF5A66). Call buttons are red; WhatsApp stays green. In `styles.css` the old variable names stay (`--yellow*` now hold the reds, `--navy*` the blacks). Logo files: header `logo-head-v4-*` (face crop), footer `logo-icon-v4-*` (badge without words or number), favicons `favicon-v4-32.png` + `favicon.ico` (face), home-screen/app icons `apple-touch-icon-v4.png`, `icon-v4-*` (full badge), schema logo and zh hero `logo-badge-v4-*` (full badge), share image `og-v4.jpg`. Masters in `_build/brand/`. Bump the version in file names when art changes, because /assets/ is cached for a year. The logo was made with Dola AI: the watermark is cropped off; a clean vector redraw is still to do for print.
- `_redirects` holds 301s from the old Wix URLs. `/review` is a 302 to the Google review form (short link for WhatsApp/QR). `_headers` is generated: change `HEADERS` in `build.py`, not the file.
