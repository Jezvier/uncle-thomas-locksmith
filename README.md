# Uncle Thomas Locksmith — Website

A fast, mobile-first, SEO-optimised website for **Uncle Thomas Locksmith** (Singapore), a 24/7 islandwide emergency locksmith, trusted since 1998.

## 📂 Files
| File | Purpose |
|---|---|
| `index.html` | The full website (single page) |
| `styles.css` | All styling (brand colours: golden yellow + navy) |
| `script.js` | Minimal JS (footer year) |
| `robots.txt` | Tells search engines to index the site |
| `sitemap.xml` | Helps Google discover pages |
| `assets/logo.jpg` | **You must add this** — your logo (see `assets/README.txt`) |

## ⚙️ SEO features included
- `<title>` + meta description targeting "locksmith SG / near me / emergency locksmith"
- **LocalBusiness / Locksmith structured data** (schema.org) — key for Google local results
- **FAQ structured data** — eligible for rich results
- Open Graph + Twitter cards for social sharing
- Geo tags, canonical URL, semantic headings (one H1)
- `robots.txt` + `sitemap.xml`
- Mobile-first, fast static site (great Core Web Vitals)
